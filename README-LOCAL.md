# FishCare AI local preview

This folder contains the latest modified static website.

## Start locally

Open Terminal in this folder and run:

```bash
npm start
```

Then visit:

```text
http://127.0.0.1:8080/
```

If you want to use port 4173 and it is free:

```bash
npm run start:4173
```

Then visit:

```text
http://127.0.0.1:4173/
```

If port 4173 shows an empty response, another old preview server is occupying it. Use port 8080 instead.
